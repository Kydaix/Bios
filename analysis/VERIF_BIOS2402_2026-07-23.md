## Paramètres remis par défaut par la MAJ (à réappliquer via BiosTuner)

La MAJ a réinitialisé principalement les menus **AMD CBS / AMD Overclocking** ;
les réglages des menus ASUS ont survécu.

### Mémoire (le plus touché)
- `mem_latency` : Gear Down Mode → Auto ; Power Down Enable (×3) → Auto.
  (UCLK DIV1 et Memory Context Restore ont survécu.)
- `nitro` : tous les réglages Nitro (RX/TX Data, Control Line, Burst Length, DFE Vref,
  Robust Training) → Auto. Seul le toggle DDR5 Nitro Mode a survécu.
- `twr_48` : Twr → Auto/0.
- `trefi` : Refresh Interval → Auto/0 (aucun palier appliqué).
- `fclk` : état incohérent — token 149 (ASUS) = **2100 MHz**, mais FCLK Frequency (3013)
  et Infinity Fabric (9A, AMD OC) = **Auto**. Le palier fclk_2100 n'est appliqué qu'à 1/3.

### PCIe / Système
- `PCIEX16(G5) Link Mode` → Auto (cible : GEN 5).
- `PSPP Policy` → Disabled (cible retenue : **Performance**, décision du 23/07/2026).
- `iGPU Configuration` → Auto (le toggle principal Integrated Graphics a survécu).

### Alimentation avancée
- `soc_d3_off` : les 9 réglages SOC * D3 → **Enabled** (cible : Disabled).
- `ACPI Sleep State` → S3 (cible : Suspend Disabled).

### CPU
- `curve_neg30` : All Core CO Magnitude actuel = **5** (cible retenue : **30**,
  décision du 23/07/2026 — à réappliquer puis valider la stabilité).

## Écarts connus / par construction (aucune action)
- `asus_neutralize` : les copies ASUS reflètent les valeurs AMD OC au lieu d'Auto —
  conflit cible déjà relevé dans `AUDIT_rules_vs_bios.md`.
- Paliers FCLK/tREFI non sélectionnés : en écart par construction (exclusifs).
- `Enable Hibernation` = 0, `SMART Self Test` = 0, `Max CPU Boost Clock Override(+)`
  (2FD6) = Auto : conformes (artefacts d'affichage du diff).
